# Tecnotitan SEO indexing and monitoring

## Search engine setup

- Add `https://www.tecnotitan.com/` as a domain property in Google Search Console.
- Verify ownership through DNS in GoDaddy when possible. Avoid hardcoding temporary verification tokens in the site.
- Submit `https://www.tecnotitan.com/sitemap.xml` in Google Search Console.
- Add the same property in Bing Webmaster Tools and import from Google Search Console when available.
- Submit the sitemap in Bing after verification.

## Weekly organic review

- Review indexed pages, excluded pages and crawl errors.
- Track impressions, clicks, CTR and average position by page.
- Compare ES, EN, PT, ZH, JA and KO clean paths for hreflang behavior.
- Watch queries around `IA para empresas`, `software para pymes con IA`, `automatizar atención al cliente con IA`, `consultoría IA Colombia` and `software empresarial a medida`.
- If a page gets impressions but CTR below 2%, rewrite its title and description.
- If a page gets positions 8-20, expand content with examples, FAQs and internal links.
- If a page gets no impressions after 30 days, check internal links, sitemap inclusion and query intent.

## Monthly content actions

- Publish at least one new B2B guide targeting a specific problem, industry or country.
- Add internal links from the home page, services page and AI hub to new guides.
- Refresh one existing guide with examples, FAQs and stronger calls to action.
- Review Vercel Analytics and deck/contact events against Search Console landing pages.
